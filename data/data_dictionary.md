# 微藻培养数据字段说明

| 字段 | 类型 | 含义 | 备注 |
|---|---|---|---|
| `culture_id` | string | 培养重复编号 | 例如 `T20_R01`；同一培养重复跨天重复观测 |
| `temperature_c` | integer | 培养温度（摄氏度） | 本数据仅包含 20、25 两组 |
| `day` | integer | 培养后观测日 | 0–7，共 8 个时间点 |
| `od680` | float / blank | 680 nm 光密度模拟测量值 | 含少量缺失、一个负值及 IQR 候选异常值 |
| `measurement_date` | ISO date string | 测量日期 | 日期按观测日递增，仅用于任务结构展示 |
| `batch_id` | string | 批次编号 | B01–B03；不在本例的主要统计检验中建模 |

**唯一记录键：** `(culture_id, day)`。

**数据规模：** 2 个温度 × 18 个培养重复 × 8 天 = 288 个预期唯一组合。CSV 另附 4 行完全重复记录，因此原始文件 292 行。
